Getting started

What it takes to connect

One integration, two options — a daily file drop or a live API. Most partners start on files and move to API later. Neither needs work from your core platform team beyond an export and a credential.

How data moves
Daily file over SFTP

A single unified file per portfolio in the layout agreed at scoping. Files land on our SFTP daily; structured errors flow back the same way, so bad rows are caught on ingest rather than after impact.

Or a versioned API

Daily placements, transactions and direct payments against a versioned API contract, with real-time validation on every field.

Payments

Stripe handles local processing and settlement. Configured during onboarding against your entity.

Test environment

A test placement environment for full lifecycle dry runs before a single real account moves.

All we need from you

The full list. Nothing else is required to run a test.

SFTP or API credentials
Test access first, production later.
An agreed file layout
Field mapping locked during scoping, then held consistent per drop.
Brand assets
Logo, colour palette and tone-of-voice guide for the customer portal and comms.
Stripe onboarding
KYC business and personnel details to confirm the payments account.

Your effort: a scoping call, a file layout to sign off, and the credentials above. We build the mapping against your file and bring it back for you to confirm, rather than handing your team a spec to implement.

Getting started

A test cohort live in eight weeks

A proof of concept is a narrow slice of the book, run end to end on the real platform — not a demo environment. Eight weeks from go-ahead to first live placements, with daily reporting from the first account. Nothing about the sequence below is bespoke; it is how every InDebted onboarding runs.

01
Week 0
Kick-off

Cross-functional team stood up the week you give us the go-ahead.

02
Weeks 1–2
Scope the test

Portfolio slice, data fields, channel mix, language split and success measures agreed.

03
Weeks 2–4
Connect

File or API exchange built and validated against the test environment.

04
Weeks 4–6
Dry run

Full lifecycle dry runs. Compliance ruleset and bilingual comms approved by your team.

05
Weeks 6–8
First placements

A live test cohort placed, decisioned and worked end to end.

06
Week 8 onward
Read the result

Daily KPIs from the first placement; liquidation read against your control group.

Eight weeks from go-ahead to first live placements. That is our standard sequence, not a stretch target. Where the test cohort is narrow — one product, digital channels only, placed on file — the scoping and connect weeks compress further.

How we would judge it: Liquidation against a matched control cohort worked over the same window, with the Spanish-preference segment read separately so the bilingual effect is visible on its own. We agree the threshold with you before the first account is placed.
